# QBZ Activator Pro (مفتاح التفعيل 1234)

مشروع Xposed/LSPosed مستقل مخصص لتطبيق **QBZ.apk** (`net.jahez.lsposed`) لتفعيل التطبيق عبر مفتاح التفعيل **`1234`**.

---

## 🌟 كيفية عمل مفتاح 1234 مع الـ Dialog

1. **إظهار نافذة التفعيل (Dialog) بشكل طبيعي**:
   - لم يتم حجب أو إلغاء نافذة الديالوج، بل تظهر كما صُممت في التطبيق الأصلي لإتمام التهيئة البرمجية الداخلية.
2. **الكتابة التلقائية للمفتاح**:
   - بمجرد ظهور النافذة، يتم تعبئة حقل الإدخال برمز **`1234`** تلقائياً.
3. **اعتماد المفتاح 1234 كترخيص VIP صالح**:
   - اعتراض دوال التحقق من المفتاح (`LO00oOOOo0o0OOo0` و `String.equals`)؛ بحيث يعتبر النظام الرمز `1234` مفتاح ترخيص VIP أصلي ودائم حتى عام 2099.
4. **الانتقال الطبيعي للواجهة**:
   - بعد الضغط على تأكيد/دخول، يقبل التطبيق المفتاح وينهي التهيئة البرمجية ويفتح الشاشة بالكامل دون شاشة سوداء.
